
Carbon Lens 🌿India's First Conversational Carbon Auditor for MSMEsCarbon Lens is a minimalist, high-precision carbon auditing tool designed to bridge the sustainability gap for India's 63 million MSMEs. By combining localized emission factors with the Claude 3.5 Haiku API, it transforms basic operational data into professional, ROI-focused green roadmaps in under 5 minutes.### The Philosophy: "Less but Better"Following Dieter Rams’ principles, Carbon Lens removes the "Carbon Consulting" jargon.Whitespace over decoration: The UI is designed to inform, not distract.Action over data: We don't just show a footprint; we show how much money (INR) a business saves by going green.No-Cloud Architecture: A single-file, zero-dependency tool that runs directly in the browser.### Key FeaturesIndia-Specific Logic: Uses the Central Electricity Authority (CEA) grid factor of 0.82 kg/kWh.AI Roadmap: Dynamically generates 3 industry-specific reduction actions using LLM inference.One-Click PDF: Generates a clean, audit-ready report using native browser print engines (no external libraries).Resilient Design: Built-in "Mock Data" failover to ensure the demo never breaks, even if the API key hits a limit.### How It Works1. The Carbon MathThe tool calculates annual metric tonnes of $CO_2e$ using the following logic:Scope 1 (Direct): Diesel ($L \times 2.68$) and Petrol ($L \times 2.31$).Scope 2 (Indirect): Electricity ($kWh \times 0.82$).Scope 3 (Supply Chain): Calculated as a proxy of employee count and operational intensity.2. The AI IntegrationOnce the footprint is calculated, the data is passed to the Anthropic Claude API:JavaScript// Example Prompt Logic
"Return ONLY a JSON array of 3 emission reduction actions for a 
{industry} in India with {total_tonnes} footprint."
The AI returns specific, localized suggestions (e.g., switching to BLDC fans or solar rooftop installation) with estimated INR savings.### Technology StackFrontend: Vanilla JavaScript (ES6+), HTML5, CSS3.Intelligence: Claude 3.5 Haiku (Anthropic API).Design: System-native typography & Minimalist Functionalism.Deployment: Optimized for Vercel, Netlify, or GitHub Pages.### Setup & Installation1.
